BUGS FIXED (9 TOTAL)
================================================================================

CRITICAL BUGS (Would cause wrong behavior):
  ✅ Collision detection race condition
     - setState inside setState causing missed collisions
     - Fixed: Pure function with gameStateRef

  ✅ Stale distance state in closure
     - maxDistance captured at game start, never updates
     - Fixed: gameStateRef.current maintains current values

  ✅ Inverted payout logic
     - Low distance = full payout (backwards!)
     - Fixed: Unified payout based on distance multiplier

  ✅ Nonce never incremented
     - Breaks provably fair uniqueness
     - Fixed: Increment on each game

IMPORTANT BUGS (Would cause issues):
  ✅ Obstacle re-render on every frame (80% of renders)
  ✅ Player lane set twice on game start
  ✅ No error handling for bad provably fair
  ✅ Magic numbers everywhere (hard to maintain)
  ✅ No pure functions (hard to test)
